# 資安從我做起｜年度資安宣導動畫課程

年度資訊安全宣導的標準教材：一般同仁與管理者適用，由 **講師 Allan**（台灣男聲）主講、**助教阿拉蕾**（可愛女聲）串場，以 Q 版動畫、對話與管理實務案例說明資安基本觀念。

## 課程內容（約 27 分鐘）

| 章節 | 主題 | 重點與案例 | 對應課後測驗 |
|---|---|---|---|
| 開場 | 資安是大家的事 | 課程地圖、CIA 三要素 | 第 7 題 |
| 第一章 | 社交工程防範 | 釣魚信件找碴、常見手法；案例：BEC 匯款帳戶變更、冒充維修人員尾隨、冒充 IT 騙 MFA 驗證碼 | 第 1、8 題 |
| 第二章 | 密碼管理 | 弱密碼排行、通行碼片語、MFA、便利貼、Win + L；案例：共用帳號與離職員工 | 第 2、3、4 題 |
| 第三章 | 資料保護 | 資料分級、公共 Wi-Fi／VPN、USB、生成式 AI、資料銷毀；案例：私人 LINE／雲端傳報價單 | 第 6、9 題 |
| 第四章 | 資安事件通報 | 應通報的狀況、勒索軟體五步驟；案例：週五晚上的「當機」、寄錯信不敢說 | 第 5 題 |

共 8 個「管理實務案例」，每個案例皆以 **情境 → 問題在哪裡 → 管理對策** 呈現，並標示主管應負的管理責任。每章末另有「隨堂小測驗」。

課後測驗不內建於本課程，由控制列「📝 課後測驗」、章節選單與課程結尾按鈕另開新視窗連到外部測驗（預設：https://allanloplus.github.io/ISMS_QUIZ66/ ）。

## 使用方式

### 1. 線上互動版（建議）
直接用瀏覽器開啟 `course/index.html`（雙擊即可，不需要伺服器），或將整個 `course/` 資料夾放到公司內網 Web 伺服器／SharePoint／LMS。

- **章節選擇**：開始畫面的「選擇章節」或控制列「☰ 章節」，可跳至任一章節；已完成的章節會打勾
- **播放控制**：播放／暫停（空白鍵）、上一句／下一句（← →）、時間軸點選跳轉、0.8x～1.5x 速度、字幕開關、全螢幕（F）
- **記憶進度**：再次開啟時可「繼續上次進度」（存在使用者瀏覽器）
- **課後測驗**：連結至外部測驗網址（另開新視窗，播放會自動暫停）

### 2. MP4 影片版（上傳 LMS／影音平台）
```bash
npm i -g playwright            # 或專案內安裝
node tools/export_video.js     # 輸出 video/00-intro.mp4 … 06-summary.mp4
```
影片為 1280×720、含配音與字幕，每章一支。

## 客製化

| 想修改 | 位置 |
|---|---|
| 公司名稱、資安窗口電話／Email、課後測驗網址 `quizUrl` | `course/js/course-data.js` 最上方 `org`（只影響畫面，不需重產語音） |
| 台詞、畫面重點、案例內容 | `course/js/course-data.js` 的 `chapters` |
| 聲線（語速、音調） | `tools/build_audio.py` 的 `VOICES` |

修改台詞後重新產生配音（只會重產有變動的句子）：
```bash
pip install edge-tts
python3 tools/build_audio.py
```
> 若某句沒有對應音檔，播放器會自動改用瀏覽器內建語音念出，不會中斷。
